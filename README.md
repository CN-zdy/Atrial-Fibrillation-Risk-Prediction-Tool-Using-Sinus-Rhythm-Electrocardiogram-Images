# Atrial Fibrillation Risk Prediction Tool Using Sinus-Rhythm Electrocardiogram Images

This easy-to-use tool predicts the risk of atrial fibrillation using sinus-rhythm electrocardiogram images. Please note the following:

  1:Do not upload non-ECG images.
  
  2:Only one ECG image can be uploaded at a time.
  
  3:The uploaded ECG image must use a 12 × 1 lead layout. Other lead layouts are not currently supported.

You can access the tool in the following ways: http://110.157.241.24:18024/#/
